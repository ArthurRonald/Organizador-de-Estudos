# Organizador de Estudos

## Ideia

Um sistema web para ajudar estudantes a organizar sua rotina acadêmica em um só lugar.

A ideia é permitir o cadastro de disciplinas e tarefas, com informações como data de entrega, descrição e status da atividade.

## Possíveis funcionalidades

* Cadastro de disciplinas
* Cadastro de tarefas
* Visualização das tarefas pendentes
* Marcação de tarefas como concluídas
* Organização por disciplina
* Visualização das próximas atividades

## Tecnologias

A princípio, o projeto será desenvolvido utilizando:

* HTML
* CSS
* JavaScript
* React

As funcionalidades e tecnologias podem ser ajustadas ou ampliadas ao longo do semestre.
